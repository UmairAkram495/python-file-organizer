# Python File Organizer

A simple Python automation script that organizes files into folders based on their file type.

## Features

- Automatically creates folders
- Organizes Images
- Organizes Videos
- Organizes PDFs
- Moves remaining files to Others

## Technologies

- Python
- os
- shutil

## How to Run

1. Clone this repository

```bash
git clone https://github.com/UmairAkram495/python-file-organizer.git
```

2. Run

```bash
python FileOrganizerScript.py
```

## Example

Before:

```
Downloads/
photo.jpg
movie.mp4
book.pdf
notes.txt
```

After:

```
Downloads/
Images/
Videos/
PDFs/
Others/
```
